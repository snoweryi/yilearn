2. 第一科重點筆記：淨零碳規劃管理基礎概論

國際趨勢與COP碳定價CBAM SBTiTCFD／ISSB碳中和標準台灣淨零路徑

2.1 國際趨勢與重要倡議

  • 京都議定書（1997）→巴黎協定（2015，COP21）：設定全球升溫控制在工業化前水準以上 2°C 內，並努力控制在 1.5°C 內。
  • COP26（2021，格拉斯哥）：確立「淨零排放」成為全球共識用語，多國宣示 2050 淨零目標。
  • 國家自定貢獻（NDC）：各國依巴黎協定自行提報的減碳承諾。
  • 常考混淆點：京都議定書僅約束已開發國家；巴黎協定則要求所有締約國都提出減碳承諾。

2.2 碳定價與國際碳稅關貿政策

  • 碳定價五大工具：碳稅、ETS（總量管制交易）、碳信用／抵換、CBAM、內部碳定價（詳見比較表）。
  • CBAM（歐盟碳邊境調整機制）：2023/10 過渡期（僅申報）→ 2026/1/1 正式進入定義期（財務義務生效）→ 2027/2/1 起 CBAM 證書開始買賣。涵蓋部門：水泥、鋼鐵、鋁、肥料、電力、氫。
  • SBTi（科學基礎減量目標倡議）：協助企業設定符合《巴黎協定》1.5°C 情境的減碳目標，是國際間評估企業減碳目標「是否夠積極」的常見標準。

2.3 揭露框架：TCFD → ISSB（IFRS S1/S2）

  • TCFD：氣候相關財務揭露建議，四大核心要素：治理、策略、風險管理、指標與目標。
  • ISSB（國際永續準則理事會）整合 TCFD 架構，發布 IFRS S1（一般永續揭露）與IFRS S2（氣候相關揭露），成為全球永續財務揭露的統一基準。
  • 台灣：金管會規劃上市櫃公司分階段接軌 IFRS 永續揭露準則，資本額較大者優先適用。

2.4 碳中和相關標準

  • PAS 2060：國際間常用的「碳中和實施標準」，規範組織如何量化、減量、抵換並對外聲明碳中和。
  • 碳中和聲明的基本流程：量化排放 → 訂定減碳計畫並執行 → 剩餘排放以碳權抵換 → 揭露與第三方查證。

2.5 台灣 2050 淨零排放路徑

  • 四大轉型主軸：能源轉型、產業轉型、生活轉型、社會轉型，並以科技研發與氣候法制為兩大治理基礎。
  • 法源：《氣候變遷因應法》（由《溫室氣體減量及管理法》修正而來），明定 2050 淨零排放為國家長期目標。
  • 台灣碳定價現況：碳費（2026年5月正式收費，一般費率每噸300元）已上路；ETS 尚在規劃試行階段。

3. 第二科重點筆記：淨零碳盤查規範與程序概要

ISO 14064-1ISO 14067 排放範疇 Scope 1/2/3組織邊界 數據品質內部查證

3.1 ISO 14064-1：組織型溫室氣體盤查

  • 規範組織如何界定盤查邊界、鑑別排放源、量化並報告溫室氣體排放與移除量。
  • 組織邊界劃定兩種方法：
    • 股權比例法：依持股比例認列排放量。
    • 控制權法：分為「財務控制」與「營運控制」，凡具控制權者需認列 100% 排放。
  • 排放範疇（Scope）三分類：
    • 範疇一（直接排放）：組織自有或控制之排放源，如公司自有車輛燃油、鍋爐燃燒。
    • 範疇二（能源間接排放）：購入電力、蒸汽、熱或冷卻所產生的排放。
    • 範疇三（其他間接排放）：價值鏈上下游排放，如員工通勤、商務差旅、採購商品運輸、廢棄物處理等。

3.2 ISO 14067：產品碳足跡

  • 規範單一產品「從搖籃到墳墓」的碳足跡計算方法。
  • 碳足跡五階段（生命週期）：原料取得 → 製造生產 → 配送銷售 → 使用 → 廢棄處理。
  • 常考重點：不同產品類別依「產品類別規則（PCR）」制定計算邊界與方法，確保同類產品可互相比較。

3.3 數據品質與不確定性分析

  • 數據等級（依代表性由高至低）：實測數據 > 次級（次佳）數據 > 預設值／文獻係數。
  • 不確定性分析用於評估排放量估算結果的可信度，數據來源與計算方法差異會影響不確定性程度。
  • 排放係數（Emission Factor）：將活動數據（如用電度數、用油公升數）轉換為溫室氣體排放量的轉換係數。

3.4 內部查證程序

  • 盤查完成後，組織可先進行內部查證，確認數據完整性、一致性與計算正確性，再送交第三方查證機構外部查證。
  • 內部查證常見檢查重點：排放源是否有遺漏、活動數據來源是否可追溯、排放係數選用是否恰當、計算公式是否正確。
